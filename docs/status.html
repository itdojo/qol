History · the terminal design system rebrand, 2026-08-08 → 2026-08-09

Superseded verdict: every script converted, merged to main

The scripts' emoji and basic-ANSI output was replaced by the IT Dojo terminal palette, with a generator in the vault so the shell copies of the token values cannot drift silently. A nine-task plan built the foundation and converted five scripts. A second pass converted the remaining eleven and finished one the plan had marked done. At 04467a2 the two passes totalled 27 commits and 417 passing assertions.

Running the scripts on a real terminal caught four fixes that the tests had not: TUI redraw flicker, every full-width element pinned at 80 columns by one 2>/dev/null, selection bars cut short under tmux, and a 256-color check that only seemed broken. Pass two's best catch came from shellcheck, on code that bash -n had called clean. Each lesson is in docs/working-notes.md § Gotchas. The plan is docs/superpowers/plans/2026-08-08-terminal-design-system.md, kept as written.
